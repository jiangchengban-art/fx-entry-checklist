## セッション10の利確ポイント記録＆RR比率分析実装（2026-08-03～04 前半）
- ✨ **利確記録モーダル（新規）**
  - トリガー: 履歴カード右の「💰 利確」ボタン（result === 'entered' のみ表示）
  - 入力: エントリー価格 + 損切り価格 → リスク幅自動表示
  - 利確ポイント複数追加可能（根拠プルダウン + 価格テキスト）
  - 価格変更時にRRが即座に自動計算・表示
  - `◎` ラジオで「実際に決済したポイント」を1つ指定
  - 保存時に価格未入力行は自動削除
- ✨ **RRの自動計算（符号付き）**
  - `RR = (到達価格 − エントリー価格) × 向き ÷ |エントリー − 損切り|`
  - ショートは符号反転：損切り=-1.00 / 建値=0.00 / 利確=+X.XX
  - `calcRR(entryPrice, slPrice, exitPrice, direction)` 関数で実装
- ✨ **EXIT_BASIS 定数**（利確根拠10選択肢）
  - RCI上限/下限到達、直近高値/安値到達、ラウンドナンバー、EMAタッチ、MACDクロス、建値決済、損切り、その他
  - 将来の根拠追加は1行足すだけで選択肢・統計集計に自動反映
- ✨ **統計タブ拡張**
  - **新規タイル3つ**: 平均RR（実決済ポイントの平均）、勝率（RR > 0 の割合 %）、最大到達RR（1トレード内での最大の平均）
  - **新規セクション**: 利確根拠別の平均RRランキング（根拠ごとに平均RRを算出、期待値高い順ソート）
- ✨ **履歴カード更新**
  - 利確表示: 「◎ RCI上限到達 RR +1.00 ／ 直近高値到達 RR +2.00」形式
  - 正RR → 緑色（good）、負RR → 赤色（bad）で色分け
  - 実決済フラグ関係なく全ポイント到達距離で根拠別平均を計算 → 「持っていたらどこまで伸びたか」を根拠別に比較可能
- ✨ **CSV 完全対応**
  - 新規列: `entryPrice`, `slPrice`, `exits`（JSON形式で1列格納）
  - エクスポート: `JSON.stringify()` で配列をシリアライズ
  - インポート: `parseExitsCsv()` で復元（型チェック・エラーハンドリング付き）
  - 後方互換性: セッション9以前のCSV/データもそのままインポート可能（exits は `[]` で初期化）
- 🔧 **ソート順序改善**
  - 同分記録での順序不定問題を解決（`createdAt` でフォールバック）
