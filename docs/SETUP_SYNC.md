# 複数端末で同期する設定手順（セッション28）

iPhone / PC / Android で同じ記録を見られるようにする手順です。
**一度やれば以後は自動**です。所要 15〜20分。

---

## 先にやること：ホーム画面に追加（3端末すべて）

⚠️ **これが「記録が消える」問題への本命の対策です。同期より先にやってください。**

iPhone の Safari は、**ブラウザのタブから開いただけのサイトのデータを、最後に開いてから7日で自動削除します**。
ホーム画面に追加したアプリはこの対象外になります。

| 端末 | 操作 |
|---|---|
| **iPhone / iPad** | Safari で https://jiangchengban-art.github.io/fx-entry-checklist/ を開く → 共有ボタン［↑］→ **「ホーム画面に追加」** |
| **Android (Chrome)** | 同じURLを開く → 右上の︙ → **「アプリをインストール」** または「ホーム画面に追加」 |
| **PC (Chrome/Edge)** | 同じURLを開く → アドレスバー右の⊕（インストール）アイコン |

**以後は必ずそのアイコンから起動してください。** ブラウザのタブから開くと元の状態に戻ります。

設定タブの「📱 アプリとして使う」で、いまどちらの状態か確認できます。

## Supabase の準備（PC で1回だけ）

### 1. アカウントとプロジェクトを作る

1. https://supabase.com/ を開いて **Start your project** → GitHub アカウントでサインイン
2. **New project** を押す
   - Name：`fx-entry-checklist`（何でもよい）
   - Database Password：自動生成のままでよい（**使いません**が、控えておくと安心）
   - Region：**Northeast Asia (Tokyo)**
3. 作成完了まで1〜2分待つ

### 2. テーブルを作る

左メニューの **SQL Editor** → **New query** に以下を貼り付けて **Run**。

```sql
create table app_state (
  user_id    uuid primary key references auth.users(id) on delete cascade,
  doc        jsonb not null default '{}'::jsonb,
  rev        bigint not null default 0,
  updated_at timestamptz not null default now()
);

alter table app_state enable row level security;

create policy own_row on app_state for all
  using (auth.uid() = user_id)
  with check (auth.uid() = user_id);
```

> **これは何をしている？**
> 「1ユーザーにつき1行、そこにデータを丸ごと入れる」テーブルを作り、
> **自分の行しか読み書きできない**という規則（RLS）を付けています。
> この規則があるので、次の手順で取得する anon key が外部に見えても他人にデータは読めません。

### 3. ログイン用のURLを登録する

左メニュー **Authentication** → **URL Configuration**

- **Site URL**：`https://jiangchengban-art.github.io/fx-entry-checklist/`
- **Redirect URLs** に同じURLを **Add URL** で追加

（登録しないと、メールのログインリンクを押しても戻ってこられません）

### 4. 接続情報を控える

左メニュー **Project Settings**（歯車）→ **API**

- **Project URL**（`https://xxxxxxxx.supabase.co`）
- **Project API keys** の **`anon` `public`**（`eyJhbGci...` で始まる長い文字列）

この2つをコピーしておきます。

## アプリ側の設定（端末ごとに1回）

1. アプリを開いて **⚙設定** タブ → **☁ 複数端末で同期**
2. 控えた **Project URL** と **anon public key** を貼り付けて **「接続先を保存」**
3. メールアドレスを入れて **「📧 ログインリンクを送る」**
4. 届いたメールの **Log In** を押す
   - ⚠️ **iPhone では必ず Safari で開いてください。** メールアプリの中で開くと別扱いになり、ログインが引き継がれません
   - 開いたあと、ホーム画面のアイコンから起動し直してください
5. 画面右上のチップが **✔（時刻）** になれば完了

**3端末とも同じメールアドレス**を使ってください。これが同じデータを指す目印になります。

## 使い方

- **自動で同期されます。** 記録して数秒後、アプリに戻ってきたとき、通信が回復したときに反映されます
- 右上のチップが今の状態を示します

| 表示 | 意味 |
|---|---|
| ✔ 14:32 | その時刻に同期済み |
| ⟳ 同期中 | 通信中 |
| ⚠ 未同期 | まだ送れていない（次の機会に自動で送られます） |
| ⚠ オフライン | 圏外。**記録はできます**。つながったら自動で送られます |
| ⛔ 停止中 | データの読み込みに失敗し、安全のため保存を止めています（下記参照） |

- オフラインでもこれまで通り記録できます。localStorage が常に「正」で、クラウドはその複製です
- 別々の端末で**違う時間足**を記録しても、どちらも消えずに両方残ります

## もしもの時

### 「⛔ 停止中」と赤いバナーが出た

保存済みデータが読めなくなった状態です。**それ以上の書き込みを止めて、壊れた原文を保管しています**（上書きしてしまわないため）。

1. ⚙設定 → **「↩ 直前バックアップから復元」** を試す
2. だめなら **「⬆ 全データJSONインポート」** で、取ってあるバックアップから戻す

この状態では**同期も停止します**（壊れた手元のデータでクラウドを潰さないため）。

### バックアップは定期的に

⚙設定 →「⬇ 全データJSONエクスポート」でファイルが1つ落ちてきます。
クラウド同期があっても、**月に1回程度は取っておいてください**。
同期は端末が壊れたときには効きますが、「間違って消した」が全端末に伝わるのは防げません。

## よくある質問

**Q. anon key が公開されて大丈夫？**
はい。RLS（行レベルセキュリティ）を設定してあるので、**ログインしていない人はこの鍵を持っていても何も読めません**。そういう前提で設計された鍵です。

**Q. 無料で足りる？**
個人1人分の記録は数百KB〜数MB程度です。Supabase の無料枠（500MB）で十分に収まります。

**Q. Supabase を使わずに複数端末で見たい**
⚙設定の「全データJSONエクスポート／インポート」でファイルを手で受け渡せます。自動ではありませんが、サーバーは不要です。
