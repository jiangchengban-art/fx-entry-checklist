👀 監視

📖 使い方（どこをタップすると何が起きるか）
カードは TradingView のアラートで自動的に入ります（通貨×時間足で1枚。同じ通貨でも1時間足・4時間足・日足・週足は別のカードです）。同じ通貨の他の時間足でもアラートが鳴っていると、カードに「🔗 他の足」の行が出て、時間足・向き・経過時間が分かります。向きが逆のアラートがあると「⚠逆向き」の印が付き、その行が赤くなります（買いと売りが拮抗しているので注意）。種類はアラートの時間足で決まります：⚡スキャ＝1時間足／☀デイ＝4時間足／🌙スイング＝日足・週足。上のタブで種類を絞れます。並び順は 📌ピン止め → 🎯狙い目 → 条件が揃ったもの → それ以外 → ✖ありの順です。古くなったカードは自動で消えます（スキャ6時間・デイ24時間・スイング72時間。📌・⏳待ち・メモのどれかがあるカードは消えません）。消えたカードの取引を記録したいときは、下の「＋ 通貨を手で追加」で種類と通貨を選んで作り直し、「入った」を押します。
通貨名：タップで通貨名をコピー。▲／▼はアラートの方向、1H／4H／D／W は鳴った時間足、⏰は鳴ってからの時間、🎯はネックライン付近で方向も合っている印（表示だけ）。
▲買／▼売（手で足したカード）：アラートが無いカードは方向が分からないので、通貨名の横の ▲買／▼売 をタップして自分で選びます（もう一度で解除）。選ぶと、他の足との逆向きの警告・「入った」の方向・見送りの記録にも使われます。
グランビル／RCI／MACD／ネック：タップするたびに ✅成立 → ▲微妙 → ✖不成立 → 未選択 と回ります。ネックはアラートが届いた時点で自動で入るので、違うと思ったときだけ直します。
メモ：長いメモは1行で省略されます。メモを長押しすると全部表示され、もう一度長押しで1行に戻ります（タップは編集）。
📍の価格：上（赤）は今の価格より上、下（緑）は下のネックライン。タップでコピー（TradingView にネックラインとして引けます）。📝：メモ欄を開きます。
📌：ピン止め。一番上に固定され、時間がたっても自動で消えなくなります（もう一度で解除）。⏳待ち：条件は見たが下位足の形ができるのを待つとき（週足など）。「⏳待ち」の印が付き、時間がたってもカードが自動で消えなくなります。もう一度で解除。🗑：カードをただ消します（記録には残しません）。
見送り：欄が開くので「見送りとして記録」か「⭐ 惜しい」（入らなかったが入ってもよかったかも）を選びます。⭐ は一言メモと「入るならこの価格」（約定価格・2:1の価格・約定日時。損切り・3:1・4:1 は自動で出ます）を任意で入れられます。どちらもカードは消え、そのときの条件つきで記録され、📒記録の「🗂 見送った記録」で見返せます（あとで入っていたら勝てたかを検証）。
入った：エントリー足（種類で候補が決まる）と約定価格を入れて「📒 記録する」。損切り価格・指値／逆指値・Fibo は任意です。押した時刻ではなく価格からエントリー時刻を突き合わせます。後から記録するときは「エントリー日時」も入れてください（入れた日時がそのまま記録され、突き合わせもその時刻を使います）。記録は📒記録タブに入り、カードは消えます。
＋「通貨を手で追加」：TradingView 以外で気づいた通貨を、時間足を選んで足します。3端末で同期されます。
📖 使い方
週末の分析などで、アラートが鳴る前に気づいたことを通貨ごとに書いておく場所です。🔔 アラートの一覧には出ず、時間がたっても消えません。3端末で同期されます。
＋ 候補の通貨を追加：通貨を選ぶとカードができ、メモの欄が開きます。
▲買／▼売・1H／4H／日足／週足：見ている方向と時間足（任意。タップで選ぶ・もう一度で解除）。
グランビル／RCI／MACD／ネック：監視カードと同じく、タップするたびに ✅成立 → ▲微妙 → ✖不成立 → 未選択。「→ 監視へ」で監視カードに引き継ぎます（候補のネックは自動では入りません）。
メモ：2行で省略されます。タップで全部表示。✎ でメモと狙う価格を書き直します。狙う価格・📍の価格はタップでコピー。
→ 監視へ：エントリーを考えるときに押すと、🔔 アラートの側に監視カードができます（方向・時間足・条件・メモを引き継ぐ。時間足は必須）。候補カードは「👀 監視中」の印が付いて残ります。
📋 候補あり：候補に入れている通貨で TradingView のアラートが鳴ると、そのアラートのカードに候補のメモが出ます（タップで全部表示）。
📌 は一番上に固定、🗑 は削除です。

📒 保有中

📖 使い方
3分割（2:1・3:1・4:1）は同じ価格で入り、損切りは共通の前提です。
🎯 2:1利確：利確した価格を入れて押すと、損切り・3:1・4:1 の価格をアプリが計算して表示します（損切り価格を「入った」で入れていれば価格は不要）。価格をタップでコピーできます。結果は REG になります。3:1・4:1 まで届いたかは、あとで Claude がローソク足から判定して BIG／MAX に直します（自分で直すなら右の REG／BIG／MAX をタップ）。
✖ 損切：損切りになったとき。＝ 建値：2:1に届く前に建値で終わったとき。
価格：約定価格・損切り価格の入れ間違いを直します。✎：損益（円）やメモなど詳しい編集。↩：決済を取り消して保有中に戻します。

⚙ 設定

📱 アプリとして使う

☁ 複数端末で同期

iPhone・PC・Android で同じ記録を見られるようにします。設定するとクラウドに複製が保存され、どの端末で記録しても他の端末に反映されます。オフラインでもこれまで通り記録でき、通信が戻ったときにまとめて反映されます。
ログインは不要です。起動時・画面に戻ったとき・表示中は30秒ごとに自動で取り込み、記録すると数秒後に自動で送信します。

🏷 記録の区分（既定）

👀監視の「入った」で作る記録の区分です。毎回選ばなくてよいように、ここで切り替えておきます（📚の ✎ で個別に直せます）。

🖼 チャート画像（Firebase Storage）

トレード記録フォームで添付するチャート画像の保存先です。未設定でも画像なしで記録の保存は可能です。

💾 全データのバックアップ

トレード記録・環境認識ボード・トレンド一覧を含むすべてのデータを1つのJSONファイルにまとめます。端末の乗り換えや、万一データが壊れたときの復旧に使います。定期的に取っておいてください。

🛟 復旧

保存直前の内容を1世代だけ自動で控えています。誤って記録が減ったときに戻せます。

🔍 ストレージ診断

データが毎回消える場合、複数の異なるURLから開いていないか確認できます。同じURLの「ホーム画面アイコン」から毎回起動してください。

📄 CSV（トレード記録のみ）

表計算ソフトで開きたいとき用です。環境認識ボードのデータは含まれないため、バックアップ目的なら上のJSONを使ってください。

📖 インジケーター解説

チェック作業中に指標や相場概念の見方を確認できます。各項目は「この手法での確認ポイント」→「基礎知識」の順で表示します。
